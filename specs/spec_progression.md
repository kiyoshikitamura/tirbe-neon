# 個別企画仕様書(B)：多層育成システム

本作の育成要素は、キャラクター（NPC）、スキルカード、および装備品の3つが独立した育成・限界突破の仕組みを持つ多層的な設計になっており、プレイヤーに長期的かつ深いやり込み（ハクスラ）要素を提供します。

---

## 1. NPCキャラクターの育成

キャラクター数は、主要メンバー8名と、52名の仮名称構成員の合計60名以上が初期実装されています。

### ① リリース・獲得方式 (キャラクター)
- **獲得方法**: ゲーム開始時のセットアップ、およびガチャ（スカウト）によって獲得します。従来のストーリー進行によるアンロック仕様は廃止されました。
- **初期ローンチ時**: 60名以上（主要8名 + 52名のスカウト・ヤクザ風仮構成員）を実装。

### ② レベルアップ (Lv)
- **効果**: HP、ATK、DEF、SPD、LUKなどの基礎ステータスが上昇します。
  - レベル上昇に伴うパラメータ成長は、キャラクターごとに設定された成長パターンマスタ（`character_growth_patterns`）に基づいて動的に算出されます（BALANCED, HP_TANK, ATTACKER, DEFENDER, SPEEDSTER, LUCKY_STAR などのパターンが存在）。
- **手段**: 
  - 本作では「クエスト戦闘の直接クリアによるキャラクター経験値獲得」はありません。
  - クエスト報酬やショップで獲得できるレベル強化用アイテム「トレーニング教本」とキャッシュを消費してレベルアップする「合成強化方式」のみとします。
- **レベル上限**: 初期状態では **Lv.50** が上限です。

### ③ 覚醒システム（＋値限界突破）
- **効果**: 
  - レベル上限の解放（+1ごとに上限が10解放、最大 **Lv.100** まで）。
  - 各覚醒段階に応じたステータスボーナスが付与されます。これらは覚醒マスタ（`character_awakening_master`）で定義されたパラメータ（HP, ATK, DEF, SPD, LUK）に基づいて加算されます。
  - 追加の「スキルカードスロット」の解放（初期3枠 → 最大6枠）。
- **手段**: 
  - 覚醒用アイテム「抗争の掟」とキャッシュを消費して実行します。消費するキャッシュ量も覚醒マスタで制御されています。
  - 最大 **+5** まで覚醒可能。

### ④ 覚醒上限（+5）到達後の重複救済
- ガチャ等で既に所持しているキャラクターを獲得した際、自動的に覚醒値が+1されます。
- 最大の **+5覚醒** に達している状態でさらに重複キャラクターを獲得した場合は、自動的に「抗争の掟（限界突破素材）」に変換されます。

## 2. スキルカードの限界突破（＋値） ＆ レアリティ

### ① リリース・運用ロードマップ (スキルカード)
- **スキルカード総数**: **100種類**
- **初期ローンチ時**: **40種類** を初期ガチャおよびゲーム内に実装。
- **アップデート用ストック**: 残りの **60種類** は、**30種類×2回** の追加アップデート時に「新カードパックガチャ」として順次実装・販売されます。

### ② スキルカードのレアリティ
- スキルカードには **N (Normal), R (Rare), SR (Super Rare), SSR (Super Special Rare)** のレアリティが存在します。
- **出現率傾斜**: 各レアリティの排出率や配分は、**マスターデータ管理によって出現率に傾斜（確率設定）をかけて制御** されます。

### ③ 限界突破（＋値）のパーセンテージ強化
- **効果**: 
  - 限界突破を重ねるごとに、スキルの基本効果値（ダメージ、回復量、バフ・デバフの付与率など）が **「すべて +20%」ずつパーセンテージ（%）表記で加算強化** されます。
  - （例：【Rカード】『ヘビーブロー』：ATKの 150% ダメージ）
  - （例：【+1段階】『ヘビーブロー+1』：ATKの 170% ダメージ（+20%））
- **専用スキルの限界突破**:
  - キャラクター専用のスキルカードは、通常の限界突破素材のほかに、レイドボス討伐等で得られる **「専用スキル触媒（裏の契約書）」** が必要ですが、限界突破時の強化値が通常カードよりも高く設定されています。
- **手段**: 同名のカードを重ねて合成。最大 **+10** まで強化可能。

### ④ スキル限界突破上限（+10）到達後の重複救済
- 対象のスキルカードが最大の **+10限界突破** に達している状態で、さらにガチャやドロップで同じスキルカードを獲得した場合、自動的にカードが分解され、**「スキルカード強化素材（経験値アイテム）」または「スキル交換用チケット」などのアイテムに変換** されます。

## 3. 装備品のハクスラ ＆ 育成システム

装備品は、武器・頭防具・身体防具・脚防具・アクセサリーの5スロットに対応し、初期実装とアップデート用ストックに分けて運用されます。

### ① 装備品カテゴリと実装ロードマップ

| 装備スロット | 総アセット数 | 初期ローンチ実装数 | アップデート用ストック数 |
| :--- | :--- | :--- | :--- |
| **武器 (2枠)** | **40種** | **30種** | **10種** |
| **頭防具 (1枠)** | **30種** | **20種** | **10種** |
| **身体防具 (1枠)**| **30種** | **20種** | **10種** |
| **脚防具 (1枠)** | **30種** | **20種** | **10種** |
| **アクセサリー (2枠)**| **40種** | **30種** | **10種** |

- **出現率傾斜**: 装備ガチャおよびドロップにおけるN〜SSRレアリティの配分は、マスターデータ管理で出現率に傾斜がかけられます。

### ② 装備の合成・レベルアップ
- 不要な装備品、または専用の「装備強化石（カスタム研磨石）」を合成して経験値を与えることでLvが上昇し、メインステータス（ATK/DEF等）が強化されます。

### ③ 装備の限界突破（＋値）によるオプション解放
- **手段**: 「同名・同レアリティの装備」を合成して+値を上昇させます。
- **追加オプションの解放**:
  - 装備品にランダム付与されたサブオプションは初期状態ではロックされています。
  - 装備の+値が特定の段階（**+3**、**+5**、**+10**）に到達するたびに、ロックされたオプションが1つずつ順に解放（覚醒）されます。最大 **+10** まで強化可能。

### ④ 装備限界突破上限（+10）到達後の重複救済
- 装備品が最大の **+10限界突破** に達した状態で、さらに同名装備を獲得した場合、その重複装備は限界突破に使用できなくなります。代わりに、**「装備分解機能」によって、高価値の「装備精錬アイテム（特殊工具・溶接機：オプション再抽選用）」や「有償ダイヤ」などに変換** することができます。

## 4. ユーザープロファイルレベル（プレイヤーレベル）の成長

プレイヤー自身の進行度や権限を表す「ユーザーレベル（Lv）」および「経験値（XP）」が定義されます。

### ① レベルおよび必要経験値マスタ
* **レベル上限**: 最大 **Lv.99**。
* **経験値テーブル**: 各レベルから次のレベルへ昇格するための必要経験値はマスタテーブル（`user_level_master`）で管理されます。
  * デフォルトの必要経験値設計: `next_xp = level * 100` (Lv1→2: 100 xp, Lv98→99: 9800 xp, Lv99: 0)
* **自動レベルアップ**: 獲得経験値が必要値を超えた場合、自動的にレベルアップし、余剰経験値は次レベルに繰り越されます。最大Lv99到達時はそれ以上の経験値獲得はありません。### ② 経験値（XP）の獲得手段（マスタ定義）
ユーザーが獲得する経験値（XP）はすべてマスタデータで定義され、ハードコードを排除して制御されます。
* **クエスト（派遣）完了時**:
  * 各クエスト完了時に獲得するXPは、クエストマスタ（`quests.reward_xp` テーブル、および constants `DISPATCH_COURSES.xpReward`）にて設定されます。
  * デフォルト設計（消費スタミナの10倍）: 初級（100 xp）, 中級（300 xp）, 上級（500 xp）
* **PvP（喧嘩）勝利時**:
  * PvPバトル勝利時に獲得するXPは、PvP設定マスタ（`pvp_match_rewards_master` テーブル）の `reward_xp` カラムに基づいて付与されます。
  * デフォルト設計: 勝利ごとに **150 xp** を獲得（敗北時は 0 xp）

### ③ レベルによる機能アンロック（制限）
特定のレベルに達することで、以下の重要機能が解放されます。レベル不足のユーザーは機能を利用できません。
* **ギルドへの加入**: ユーザーLv.3以上でアンロック
* **レイドへの参加**: ユーザーLv.5以上でアンロック
* **ギルドの創設**: ユーザーLv.8以上でアンロック
