# キャラクターページ仕様

最終更新: 2026-08-05

本書はキャラクターページ（`CharacterTab`）の優先仕様である。添付された『放置少女』のキャラクター画面を、情報密度と視線誘導のベンチマークとして参照する。ただし、固有の意匠、素材、UI文言は流用せず、TRIBE: NEON REIGNのMatte Outlaw / neon表現に置き換える。

共通UIの色、文字、ボタン、モーダル、ローディング、キャッシュ、安全領域、信頼境界は`ui_design_system.md`を正本とする。本書はキャラクターページ固有の機能、情報配置、レアリティ表現、編成を定義する。

## 1. レイアウト方針

- 画面中央に選択中キャラクターの全身立ち絵を大きく表示し、キャラクターを最優先の視線要素とする。
- 上部にキャラクター切替、キャラクター名、レアリティ、レベル、覚醒・限界突破などの主要情報を配置する。
- キャラクター名・属性の近くに、主ロールを1つ情報タグとして表示する。主ロールはキャラクターの得意分野を示すものであり、装備スキルの使用制限には用いない。
- 初期ロールの表示名は、アタッカー、ディフェンダー、ヒーラー、サポーター、トリックスターの5種類とする。
- ステータスまたはスキル領域に固有パッシブ欄を設け、名称、効果、現在の覚醒強化段階、次の強化条件を確認できるようにする。
- 左右に装備スロットを配置し、装着部位と装備品の状態を一目で把握できるようにする。
- 画面下部にステータス要約と装備スキル状況を常時表示する。詳細な付け替え・育成操作は、既存の中央ポップアップまたはインライン選択UIに集約する。
- 1画面内で全身立ち絵、装備、スキル、主要ステータスが把握できることを優先し、モバイルのフッターや操作領域を隠さない。

## 2. キャラクターレアリティ連動背景

選択キャラクターのレアリティに応じ、立ち絵背後の背景・フレーム・粒子演出を切り替える。背景変更は視認性を損なわず、テキストとスロットの可読性を維持する。

| レアリティ | 背景・演出 |
| --- | --- |
| N | つや消しのダークスチール、控えめなグレーの縁取り |
| R | シアン／ブルーのネオン反射、細い発光フレーム |
| SR | マゼンタ／バイオレットの光彩、控えめな粒子・グラデーション |
| SSR | ゴールドを基調にした高密度フレーム、脈動するネオン光彩、限定的なパーティクル |

- 演出の強さはSSRを最大とするが、常時過剰に点滅させない。
- `prefers-reduced-motion`または低負荷設定では、粒子・脈動を静止背景へ置き換える。

## 3. 装備・スキルアイコンのレアリティ表現

### 3.1 装備品

- 装備スロットは装備品のレアリティに応じた枠、リボン、光彩、反射表現を使用する。
- 未装備スロットは部位アイコンと「未装備」状態を表示し、誤ってレアリティ演出を表示しない。
- 装備済みスロットには、アイコン、レアリティ、強化値、ロック等の状態を表示する。
- 装備の限界突破は`+1`ごとに成功演出とステータス増加値を表示する。`+3`、`+5`、`+10`では節目到達として演出を強調するが、ユーザーに抽選・選択・厳選の概念は表示しない。
- ユーザー画面では、最終ステータスと`+値`を主表示し、詳細画面でのみ「限界突破ボーナス」として節目の追加上昇を確認できるようにする。

### 3.2 スキル

- スキルアイコンにも装備品と同じレアリティ階層（N/R/SR/SSR）に対応したフレームと光彩を適用する。
- スキルの高レアリティ演出は、アイコン自体を読みづらくしない範囲で、外枠・角飾り・微細な発光に限定する。
- 強化値、専用スキル、使用不可などの状態バッジはレアリティ表示と重ならない位置に配置する。

## 4. 装備スキル状況表示

キャラクターページに装備スキル状況を新設する。スキル枠は初期3枠とし、覚醒に応じて最大6枠まで拡張する。覚醒0では3枠、覚醒1では4枠、覚醒2では5枠、覚醒3以上では6枠を使用可能とする。未解放枠も表示するが、装備・付け替え操作はできない。各スロットで以下を確認できるようにする。

- 装備中／未装備
- スキルアイコン、名称、レアリティ、強化値
- クールダウン、対象範囲、主要効果
- 専用スキルかどうか（装備キャラクターと`exclusive_character_id`が一致するか）
- 使用可能状態。戦闘中にのみ確定するクールダウン・沈黙などの状態は、常時表示では「戦闘状況により変動」として扱う。

スキルスロットを選択すると、詳細表示および既存の付け替え操作へ遷移できる。未装備スロットからも同じ付け替え導線を提供する。

- スキルは初回入手時にアカウントへ恒久解放する。重複入手はスキルID単位の覚醒・限界突破素材として扱い、元のスキルの解放状態は失わない。
- 同一スキルIDは、同一キャラクターの複数スキル枠に重複して装備できない。同一パーティ内を含む別キャラクターへの装備は許可する。同名でもスキルID・レアリティ・効果が異なる別スキルは装備可能とする。
- 専用スキルは、`exclusive_character_id`が一致するキャラクターにのみ装備できる。おまかせ編成によるスキル自動装着も同じ制約に従う。
- 専用スキルの追加専用枠は設けない。専用スキルは、覚醒で解放される通常の3〜6スキル枠の1つとして装備する。高い効果量・固有の追加効果により、通常枠を使う編成上の価値を持たせる。

## 5. 表示優先度とパフォーマンス

- 初期表示では、選択キャラクターの立ち絵、背景、画面内の装備・スキルアイコン、UI画像を一つの画面アセットマニフェストとして読み込む。
- 必須データと画面アセット一式が揃うまで共通スピナーを維持し、読み込み完了順の段階表示を行わない。
- キャラクター切替時に次候補をバックグラウンドで先読みできるが、先読み途中の画像は画面へ露出しない。切替対象の一式が未準備なら現在表示を維持してスピナーを表示する。
- レアリティ演出はCSS中心で実装し、重い動画・大量の常時アニメーションを避ける。
- 画像領域の寸法はロード前から確保する。必須画像に失敗した場合は、事前ロード済み代替画像へ解決するか、部分表示せず再試行可能なエラー状態を表示する。

## 6. パーティ編成

- キャラクターページ内に編成領域を設け、バトル前に恒常的な出撃パーティを編集・保存できるようにする。バトル開始直前にキャラクター、装備、スキルを都度操作させない。
- 出撃パーティはユーザー所持キャラクターを最大5体まで登録できる。最低1体から出撃可能とし、前衛・後衛および配置による役割差は設けない。
- クエストNPC戦およびレイドには、選択した友達リーダーをヘルパーとして最大1体追加できる。したがって、PvEの出撃枠は「ユーザー所持キャラクター最大5体＋友達リーダー1体」の最大6体とする。PvPおよびGvGでは友達リーダーを使用せず、所持キャラクター最大5体のみで対戦する。友達リーダーの利用条件・更新・重複利用制限は友達機能仕様で定義する。
- おまかせ編成は初期実装では、PvE・対人共通の「バランス編成」のみとする。アタッカー、ディフェンダー、ヒーラーのロール分散を優先し、残り枠はサポーター、トリックスターを含む総合評価の高いキャラクターで補完する。必要なロールを所持していない場合は、総合評価上位のキャラクターを選出して編成不能にならないようにする。
- おまかせ編成は、友達リーダーを除く所持キャラクターから最大5体を選出する。装備・スキルの自動装着優先度、ロール別評価値、ロール不足時の代替優先度は、おまかせ編成マスタで管理する。
- 装備の自動装着は7枠すべてを対象とし、装備可能条件を満たす候補からロール別評価で選択する。同点時は、レアリティ、装備レベル、限界突破値、反映済み限界突破ボーナス評価の順に優先する。同一の装備インスタンスを複数キャラクターへ重複装着しない。
- 装備評価では、アタッカーはATK・攻撃系パッシブ・SPD、ディフェンダーはHP・DEF・シールド／挑発系、ヒーラーはHP・DEF・回復／デバフ解除系、サポーターはSPD・HP・DEF・強化／解除系、トリックスターはSPD・状態異常成功率・妨害系を重視する。
- スキルの自動装着は、覚醒で解放済みの3〜6枠のみを対象とする。ロールに合う主力スキルを1つ選んだ後、通常攻撃とは異なる役割のスキルを優先して選択する。追加枠では短・標準・長クールダウンが極端に偏らないようにし、同一スキルIDは選択しない。専用スキルは対象キャラクターで使用可能な場合にロール適性を高く評価する。
- おまかせ実行時は、変更予定のキャラクター、装備、スキルを確認してから保存する。チュートリアル中はナビゲーションに従う1タップで実行し、確定した編成結果を表示する。
- 編成画面ではキャラクターカードに主ロールアイコンを表示する。バトル画面では常時大きく表示せず、詳細表示から確認できるようにする。
- PvPおよびGvGの防衛デッキは、キャラクターページの編成領域で登録する。防衛デッキの作戦は登録・更新時のみ変更でき、攻撃を受ける直前や開催中に変更できない。
- 攻撃側の作戦は、バトル開始直前の確認画面でのみ変更できる。キャラクター、装備、スキルの変更が必要な場合は編成画面へ戻る。
- バトル開始直前の確認画面では、敵の属性、各パラメータ、総合力、装備スキルを表示する。それ以外の詳細な行動ロジック、隠し補正、内部確率は表示しない。

## 7. 既存横断仕様との整合

- 既存文書にある「5人固定編成」「作戦6パターン」「クエスト派遣は最大3名」といった旧記述は、本書および`spec_battle_system.md`の決定と整合させる必要がある。通常バトルの編成は本書の最大6体を優先し、派遣機能における別枠の人数制限を残す場合は、戦闘出撃編成と明確に区別して記載する。

## 8. 受け入れ条件

- 選択キャラクターのレアリティ変更に応じて、背景・フレームが正しく切り替わる。
- 装備品とスキルのレアリティがアイコンフレームに反映される。
- 覚醒段階に応じて3〜6枠の装備スキル枠が解放され、装着状況と主要情報をキャラクターページから確認できる。
- 未装備の装備・スキルスロットから付け替え操作へ進める。
- モバイル画面で全身立ち絵とフッターメニューを同時に視認できる。
- ユーザー所持キャラクターを1〜5体、友達リーダーを最大1体追加して出撃編成を保存できる。
- 前衛・後衛・配置UIを表示しない。
- 攻撃側は開始直前に作戦のみ変更でき、防衛側の作戦は防衛デッキ登録時のみ変更できる。
