# ユーザープロフィール・ギルド・コミュニケーション統合仕様

共通UIデザイン、ロード方式、信頼境界は`ui_design_system.md`を正本とする。本書はプロフィール、ギルド、チャット、BBS、フレンドの固有ルール、権限、必要表示項目を定義する。

最終更新: 2026-08-05

本書はユーザープロフィール、ギルド、チャットおよびBBSに関する優先仕様である。既存の個別仕様と内容が異なる場合は、本書を優先する。

## 1. ユーザープロフィール

### 1.1 表示内容

プロフィールには、以下を表示する。

- 称号
- ユーザーネーム: 1文字以上8文字以内
- アイコン: リーダーに設定されたキャラクターのアイコン
- 自己紹介テキスト: 最大200文字
- ユーザーレベル
- 現在のユーザー経験値（XP）
- 所属ギルド情報: ギルド名、ギルドレベル、所属人数/最大人数、本人の役職

任意画像をアイコンとしてアップロードする機能は対象外とする。自己紹介の文字数上限は、クライアントとサーバーの双方で検証する。

ギルド未所属の場合は、所属ギルド情報を「未所属」と表示する。プロフィールに表示するギルド情報は公開可能な概要のみとし、ギルド資金、加入申請、内部ログ、権限設定などの非公開情報は含めない。

### 1.2 XP・レベル・機能解放

- ユーザーXPは、クエスト完了およびレイド完了時に自動で付与する。
- XP値は各コンテンツの報酬マスタの `reward_xp` で定義する。クライアントやコンテンツ処理に固定値を持たせない。
- レイドでは、討伐完了報酬として参加資格を満たすユーザーにXPを付与する。ダメージランキング報酬などの個別報酬とは別に扱う。
- PvPおよびGvGの結果ではユーザーXPを付与しない。
- ユーザーレベル上昇による直接の戦闘パラメータ上昇はない。ユーザーレベルは機能のアンロック条件として使用する。
- 機能ごとの解放レベルはマスタまたは設定値で管理し、未解放時は必要レベルをUIに表示する。

### 1.3 称号・プロフィール編集

- 称号は装備中の称号を表示する。称号に性能効果は持たせず、コレクション・自己表現要素として扱う。
- 称号の初期入手経路は、通常ミッション・実績、PvP／GvGのシーズン順位、イベント、特別配布の4系統とする。課金限定称号は初期実装では設けない。
- 一度取得した称号は永久に所持する。シーズン称号も「第○シーズン」等の識別を付けて永久保存する。
- 装備できる称号は1つとし、称号の変更回数に制限は設けない。称号マスタで表示名、説明、入手条件、カテゴリ、表示順、アイコンを管理する。
- ユーザーネームと自己紹介テキストは、それぞれ1日1回まで変更できる。
- 日次制限はJSTの00:00でリセットする。最終変更日時の保存・日次制限の判定はサーバー側で行う。

## 2. ギルド

### 2.1 基本情報と役職

ギルドは、ギルド名、ギルドマスター、複数の副マスター、ギルドメンバー、ギルド資金を保持する。

| 役職 | 権限 |
| --- | --- |
| `MASTER` | ギルドの管理およびギルドUIアイテムの配置変更 |
| `SUB_MASTER` | メンバーとしての通常機能に加え、ギルドショップでギルド資金を消費するUIアイテムの購入が可能。UIアイテムの配置変更、役職変更、加入・脱退管理は不可 |
| `MEMBER` | メンバーとしての通常機能 |

### 2.2 人数上限

- 初期の最大人数は10人とする。
- ギルドレベルの上昇により人数上限を段階的に増加させ、最大20人とする。
- 各ギルドレベルの人数上限はギルドレベルマスタで管理する。

### 2.3 資金・献金・ギルドショップ

- ギルド資金の通貨はCashのみとする。
- メンバーはギルドへCashを献金できる。献金額、回数制限、貢献度への反映は献金マスタまたは既存の献金仕様で管理する。
- ギルドページにギルドショップを設置する。
- ギルドショップではギルド資金を消費して、ギルドページ用のUIアイテムを購入できる。
- UIアイテムはショップ購入のほか、イベント、GvG、レイドなどの報酬でも獲得できる。
- 購入・報酬で得たUIアイテムはギルド単位の所持品として保存する。購入と資金消費は原子的に処理し、サーバー側で権限と残高を検証する。

### 2.4 ギルドページのUI

- ギルドレベルに応じて、ギルドページのベースUI、装飾可能な領域、演出段階を変化させる。
- 解放内容はギルドレベルマスタで管理する。
- 所有済みUIアイテムの配置変更は`MASTER`のみ実行できる。`SUB_MASTER`および`MEMBER`は閲覧のみとする。
- ギルドショップでのUIアイテム購入は`MASTER`および`SUB_MASTER`が実行できる。所有済みUIアイテムの配置変更は引き続き`MASTER`のみとする。

## 3. チャットとBBS

### 3.1 チャット種別

リアルタイムチャットは以下の3種とする。

| チャンネル | 対象 | 用途 |
| --- | --- | --- |
| 全体チャット | 全ユーザー | 全体への会話・システム速報 |
| ギルドチャット | 同一ギルドのメンバー | GvG・レイド等の作戦会議 |
| DM | ユーザー間の1対1会話 | 個別連絡 |

- 通常のDM宛先選択は、フレンドおよび同一ギルドメンバーをプルダウンに表示する。
- ランキング、全体チャット、ギルドチャット、BBSなどで他ユーザーを選択した場合は、共通のプロフィール・ポップアップを開く。
- プロフィール・ポップアップからDM作成画面へ遷移できる。ポップアップは称号、名前、リーダーキャラクターアイコン、自己紹介、ユーザーレベルのみを表示し、通貨・所持品などの非公開情報を表示しない。

### 3.2 BBS

BBSはスレッド形式とし、カテゴリは以下の2種とする。

- ギルドメンバー募集
- 攻略＆雑談

既存の文字数制限、投稿クールダウン、リアルタイム更新、通報・モデレーション方針は、`spec_bulletin_board.md`の定義を継続して適用する。

### 3.3 コミュニティ画面の導線

- 既存のコミュニティページに「チャット」と「BBS」の入口を併設する。
- チャット入口では全体、ギルド、DMを切り替える。
- ギルド未所属ユーザーはギルドチャットを選択できず、加入またはギルド検索への導線を表示する。
- BBS入口では「ギルドメンバー募集」と「攻略＆雑談」を切り替える。

## 4. 既存仕様からの変更点

- ギルド人数上限は、既存の最大30人ではなく最大20人とする。
- ユーザーXPの獲得元はクエスト完了とレイド完了のみとし、PvP勝利XPは廃止する。
- プロフィールの名前・自己紹介の変更は、JST基準で各項目1日1回までとする。
