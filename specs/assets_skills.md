> **仕様統合メモ（2026-08-05）**：本書の「カード」はUI・アセット表現を指す。スキルの所持はアカウント単位のスキルID恒久解放であり、重複取得は限界突破素材となる。以降に残る「AP」「得意AP」「シナジー（AP-1）」の列・記述は旧仕様であり、ゲームロジックには使用しない。これらはスキル固有のクールダウン、対象テンプレート、効果量、状態異常条件へ置換する。対象・クールダウンの正本は`spec_battle_system.md`とする。

## 2. 成長・限界突破（`plus_val`）スケーリング規約
- **効果量・威力倍率**: 限界突破（`plus_val`）に伴い、威力・回復量・バフ/デバフ効力数値（`power_multiplier`）が成長します。標準曲線は`+1〜+3`が各+5%、`+4〜+6`が各+4%、`+7〜+9`が各+3%、`+10`が+5%で、合計+41%とします。`+3`は既存効果の扱いやすさ、`+6`は同一対象テンプレート内の副次効果、`+10`は固有の条件付き強化を設定できます。対象範囲拡張、全体沈黙・全体スタン、クールダウン短縮は追加強化でも許可しません。
- **ターン数・クールダウンの固定化**: 対人戦ハメ防止とバランス維持のため、バフ／デバフの持続ターン数およびスキル固有クールダウンは、限界突破で短縮しない。個別値はスキルマスタで定義する。
- **スタン (STUN / 行動不能)**: `JAMMER` に分類される1ターン行動不能デバフ。対象の手番が回ってきた際に手番を1ターン自動スキップさせます（※連続ハメ防止のため持続は1ターン固定）。

## 4. スキルシステム機能仕様

### ① スキル限界突破段階に応じたスロット・アイコンの豪華化 (最大+10)
スキルスロット（`char-skill-slot-box`）および所持スキル一覧のグリッドアイコンについて、セットされているカードの限界突破値（`plus_val`）によって以下の変化を適用します。
*   **+0〜+2**: レアリティに応じたベーシックな枠。
*   **+3〜+5**: シルバーの微弱な脈動光彩 (`rgba(192, 192, 192, 0.4)`) ＆ 右上 `+3`〜`+5` バッジ。
*   **+6〜+9**: ゴールドの脈動光彩 (`rgba(255, 215, 0, 0.6)`) ＆ 右上 `+6`〜`+9` バッジ。
*   **+10 (MAX)**: 激しく明滅・回転する「ネオンマゼンタ ＆ シアン」の環境反射光彩 ＆ 右上ゴールド `MAX` バッジ。

### ② ポップアップモーダルの廃止 ＆ インライン・グリッドアイコンリスト
*   スロットタップ時、右側詳細エリアに所持スキルカードのアイコンを4列のグリッド形式で並べてインライン展開します（ポップアップモーダルは廃止）。
*   アイコンにはスキルレアリティ（N, R, SR, SSR）、限界突破段階（+X）、専用スキル・装備不可などの状態バッジを重ねて描画します。
*   **詳細ポップアップ**: アイコンタップ時、画面中央または吹き出しのポップアップで威力、クールダウン、対象範囲、効果説明、および「装備する」ボタンを表示します。
*   ソート機能（`レアリティ順`、`限界突破順`、`クールダウン順`、`威力順`、`効果種別順`）を上部に配置。

### ③ スキルの一括操作（全身外す / おすすめ装着）
*   **全身外す**: `unequip_skill_bulk` RPC を用いて、対象キャラクターの全装備スキルを一括で解除します（1通信でトランザクション処理）。
*   **おすすめ装着**: クライアント側で未装備のカードから、以下の優先順位で自動選定し、`equip_skill_bulk` RPC を呼んで一括更新します。
    1.  得意スキルシナジー（キャラクターIDとスキルの専用NPC制限 `exclusive_character_id`、またはアライメント特性 `alignment` が一致するもの）を最優先。
    2.  レアリティが最も高いこと (`SSR` > `SR` > `R` > `N`)。
    3.  限界突破段階 (`plus_val`) が最も高いこと。
    4.  威力が最も高いこと。

### ④ 専用スキルの制限と装備不可時の挙動
*   **インライングリッドリストでの制御**: スロットタップ時の「所持スキル一覧」において、自身のキャラクターIDと一致しない専用スキル（`is_exclusive = true` かつ `exclusive_character_id != activeChar.id`）は、装備不可としてグリッド上でグレーアウトされタップできません。
*   **チート対策 (RPC内での厳格な検証)**:
    *   `equip_skill_bulk` RPC 内部で、送信されたスキルIDの所有権（`user_id`）がログイン中の `p_user_id` と一致しているかを検証します。
    *   専用スキルが指定された場合、そのスキルの `exclusive_character_id` が装備対象の `character_id` と一致しているかを検証し、不一致の場合はトランザクションをロールバックしてエラーを返します。
