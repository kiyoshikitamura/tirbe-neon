# ショップ・マイページ・ロード時間短縮仕様

最終更新: 2026-08-05

本書はショップとマイページ固有の優先仕様である。全コンテンツの共通ロード、画像一括表示、スピナー、キャッシュ、性能目標、信頼境界は`ui_design_system.md`を正本とする。

## 1. ショップ

### 1.1 構成

ショップは次の2タブで構成する。

| タブ | 決済手段 | 内容 |
| --- | --- | --- |
| 限定ショップ | 実課金 | 期間・購入条件を伴う有料商材 |
| 通常ショップ | Cashまたはダイヤ | ゲーム内通貨で購入する消費アイテム |

決済、付与、購入回数・期限・在庫の検証はサーバー側で行い、クライアント上の表示やタイマーを購入可否の根拠にしない。

### 1.2 限定ショップ

初期商材は以下に限定する。

- 初心者パック
- ダイヤ
- VIPパス

- 初心者パックは、アカウント作成後72時間限定とする。従来の24時間限定仕様は廃止する。
- ダイヤは実課金で購入する。商品SKU、価格、付与量、販売条件は商材マスタで管理する。
- VIPパスは実課金で購入する。特典、価格、期間、重複購入時の扱いは仮実装のため、正式な商材マスタ・課金仕様の確定後に置き換える。
- 限定ショップに上記以外の初期商材は追加しない。

### 1.3 通常ショップ

- 通常ショップではCashまたはダイヤを消費して購入する。
- 初期商材として、3種のエナジードリンクと複数のパック商品を用意する。
- 3種のエナジードリンクは、効果量・価格・通貨種別・購入制限を通常ショップ商品マスタで管理する。
- パックの内容、価格、通貨種別、購入制限は未定義である。仮の固定内容を仕様として確定せず、商品マスタで差し替え可能な構造とする。

## 2. マイページ

### 2.1 廃止する仮導線

- 仮実装のPreviewアイコンおよびPreview画面への遷移をマイページから削除する。
- Preview画面は開発・検証用途であり、プレイヤー向けのナビゲーション、フッター、メニューには表示しない。

### 2.2 VIPパス導線

- マイページ上のVIPパス直接購入処理は廃止する。
- VIPパスの情報・訴求はバナーに統合する。
- VIPパスバナーを選択した場合はショップの限定ショップへ遷移し、VIPパス商品を表示する。
- 購入確認、決済、購入結果の表示はショップ側で一元管理する。

### 2.3 拠点と背景

- マイページの背景は、現在選択中の拠点に連動して変更する。
- 拠点移動の確定後は、保存済みの現在拠点を更新し、その拠点に対応する背景を表示する。
- 拠点背景に加え、ユーザーが設定した任意背景画像をマイページに表示できるようにする。任意背景が設定されている場合は、拠点背景に代えて任意背景を表示する。
- 任意背景は取得済み・利用可能なプロフィール背景から選択する。未設定または「自動」選択時は、現在拠点の背景を表示する。
- 拠点移動と任意背景選択は別の設定として保持する。任意背景の表示中も、拠点名、支配ギルド、拠点移動ボタンなどの拠点HUDは現在拠点の情報を表示する。

## 3. 全コンテンツのロード時間短縮

### 3.1 対象と基本方針

マイページ、クエスト、キャラクター、ガチャ、ショップ、ギルド、チャット/BBS、PvP、GvG、レイド、ランキング、設定、各モーダルを対象に、画面遷移・初期表示・主要操作後の待機時間を短縮する。

- アプリ起動時に、ログイン後に必要となるプロフィール、通貨、通知数、共通マスタ、現在拠点の背景などを優先度付きで取得・キャッシュする。
- 遷移先で必要なデータは、導線の表示時またはユーザー操作の直前にプリフェッチする。
- 表示対象画面の初期表示画像は画面アセットマニフェストで一括ロードし、全て揃ってから画面を表示する。次画面の先読みはアイドル時に行えるが、先読み途中の画像を画面へ露出しない。
- 一覧・ログ・BBS・チャットはページネーションまたは仮想化を用い、初回に全履歴を読み込まない。
- 同一データへの重複リクエストを統合し、購入・報酬受取・編成保存などの更新後は必要なキャッシュのみを再検証する。

### 3.2 UI要件

- キャッシュ済みの画面は即時表示し、バックグラウンドで差分を更新する。
- 通信待ちが避けられない場合は共通回転スピナーを使用する。スケルトンによる段階表示と、`Now Loading...`や`読み込み中...`の文字ラベルは使用しない。
- 操作中の二重送信を防止しつつ、画面全体を不要にブロックしない。処理中状態は該当操作の範囲に限定して表示する。
- 計測対象は画面遷移、主要データ取得、画像表示、購入・報酬受取などの完了までの時間とする。性能予算・具体的な目標値は計測基盤の選定後に別途定義する。
- 初期の性能目標は、一般的なスマートフォンおよび4G回線を基準に、以下を計測指標として設定する。通信障害時の保証値ではなく、継続的な改善基準として扱う。

  | 対象 | 目標 |
  | --- | --- |
  | キャッシュ済み画面遷移 | 0.5秒以内に画面骨格を表示 |
  | 未キャッシュ画面の操作可能化 | 75パーセンタイルで2.5秒以内、95パーセンタイルで4秒以内 |
  | モーダル表示・タブ切替 | 0.3秒以内 |
  | 主要API応答 | 75パーセンタイルで1秒以内、95パーセンタイルで2秒以内 |
  | 主要画像の表示 | 75パーセンタイルで2.5秒以内、95パーセンタイルで4秒以内 |
  | バトル開始準備 | 75パーセンタイルで3秒以内、95パーセンタイルで5秒以内 |

## 4. 既存仕様からの変更点

- 初心者パックの販売期限は24時間ではなく72時間とする。
- マイページからのVIPパス直接購入は廃止し、VIPパスバナーは限定ショップへの遷移専用とする。
- マイページのPreviewアイコンおよびプレイヤー向けPreview遷移は廃止する。
