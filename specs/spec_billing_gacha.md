# 個別企画仕様書(E)：ガチャ ＆ ショップ ＆ Stripe課金

本作の収益モデルである「有償ダイヤ購入（Stripe決済）」、「パック商材」、「スカウトガチャ（スキル/装備）」、「構成員アンロック（ストーリー連動）」などの経済システムの確定仕様です。

---

## 1. 課金モデルとStripe連携

決済手段として Stripe を使用し、ブラウザゲームとして安全かつスムーズな課金フローを実現します。

### ① Stripe Checkout による有償ダイヤ購入
- プレイヤーはゲーム内ショップ（「闇取引」タブ）から Stripe の提供する決済画面（外部遷移）へ進み、決済を行います。
- **販売パッケージの例**:
  - `ダイヤ 100個チャージ`（1,200円相当）
- **重複決済防止（冪等性）**:
  - 決済完了時、Stripe Webhook から受信したユニークな Stripe セッションIDを `payment_transactions` テーブルに一意に保存し、すでに処理済みのトランザクションはデータベースの制約によりスキップします。

### ② パック商材の販売 (ダイヤ消費)
ショップ内の「パック商材」タブにて、有償ダイヤを消費して以下のゲーム内アイテム・ステータスパックを購入可能です。
- **初心者応援スタミナパック** (消費ダイヤ: 20) ─ スタミナを100回復（上限200まで）。
- **限界突破！抗争覚醒パック** (消費ダイヤ: 50) ─ 覚醒アイテム「抗争の掟 x1」を獲得。
- **装備強化！研磨石パック** (消費ダイヤ: 15) ─ 装備レベルアップ素材「研磨石 x5」を獲得.
- **資金調達パック** (消費ダイヤ: 30) ─ 通常通貨「キャッシュ 10,000」を獲得。

## 2. ガチャシステム (定常 ＆ 期間限定 ＆ チュートリアル)

フッターメニューの「ガチャ」タブより、「スキルカード」、「ハクスラ装備」に加えて、すべての「構成員（キャラクター）」を獲得できるスカウトガチャを引くことができます。キャラクターはストーリーアンロックや初期選択ではなく、すべてガチャでの獲得に統一されています。

### ② 重複時の救済・覚醒・素材変換処理
- **構成員（キャラクター）**:
  - キャラクターを重複して獲得した際、自動的にそのキャラクター的の「覚醒レベル（`awakening_level`）」が +1 されます（最大★5まで）。
  - すでに覚醒レベルが最大（★5）の状態で重複した場合は、覚醒用共通素材である**「抗争の掟（`LAW_OF_STRIFE`） x1」**に自動変換されて付与されます。
- **スキルカード**:
  - 重複したスキルカードを入手した際、自動的にそのカードの「限界突破値（`plus_val`）」が+1されます（最大+10まで）。
  - すでに `plus_val` が最大値的の10に達している同一カードを重複入手した場合は、自動的にスキル強化素材である**「指南書 x2」**へ変換されて `user_items` に加算されます。
- **ハクスラ装備品**:
  - 装備品はガチャごとに異なるランダムサブオプションを持つユニークなアイテムのため、重複しても変換されず、新規個体としてそのまま `user_equipments` に追加されます。

## 3. チュートリアル無料100連ガチャ ＆ 初期メンバーオミット

新規プレイヤーの登録・ゲーム開始フローは以下の通りに単純化・最適化されています。

- **初期メンバー選択の廃止**: ユーザー登録画面での初期キャラクター選択およびアバターメイキングUIは一時オミットされ、所持キャラクターが0人の状態でゲームを開始します。
- **チュートリアル無料100連の強制実行**:
  - ゲーム登録直後、所持キャラクターが0名の状態を検知すると、ガチャ画面に自動遷移します。
  - ガチャ画面では、他のガチャへのアクセスを半透明のオーバーレイガードによって制限し、コスト0の「チュートリアルガチャ（100連無料）」のみを強制的に実行させます。
- **最初の1体の初期セットアップ処理**:
  - 100連ガチャによって最初に新規獲得されたキャラクターは、自動的にお気に入りリーダーとして設定されます。
  - 同時に、そのキャラクターに適した初期スキル（レイジ = `SKILL_037`、ルイ = `SKILL_039`、その他 = `SKILL_038`）および、初期装備品（武器・頭・体・足・アクセサリーの一式）が自動付与され、装備された状態になります。これにより、ガチャを引いた直後から戦闘に参加可能な状態が担保されます。
- **交渉ストーリーのオミット**:
  - 従来のキャラクター雇用交渉ストーリー（`unlock_[charName]` などのADVパート）は完全に廃止されています。

## 4. ガチャ天井システム ＆ マイレージ確定交換所

ガチャを引いた回数に応じて「ガチャPt」が蓄積し、一定Ptに達した際に交換所から好きなキャラクター・装備を直接獲得できるシステムです。

### ① ガチャPtの蓄積 ＆ UIプログレス
- ガチャ1回ごとに **1Pt** のガチャPt（マイレージ）が `user_gacha_pity_points` テーブルに自動加算されます（10連実行時は **+10Pt**）。
- ガチャ画面（`GachaTab`）の上部には、テキストラベル（例: `120 / 200 Pt`）に加え視覚的なグラデーションプログレスバーを配置します。

### ② 天井Pt確定交換所モーダル
- ガチャ画面の「天井Pt確定交換所を見る」ボタンをタップすると、交換所モーダルが起動します。
- モーダル内では、交換可能な全キャラクターおよび最高レア装備のカードアイコン、名称、ステータス概要、必要Pt（例: キャラクター 200Pt / 装備 150Pt）、交換制限（例: あと1回）を明示的に一覧表示します。
- 必要Ptを所持している状態で「交換する」をタップすると、即座にアセットが `user_characters` / `user_equipments` へ付与（所持上限オーバー時は `presents` へ自動退避）され、所持Ptが消費されます。
