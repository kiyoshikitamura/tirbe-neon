# 設定仕様

最終更新: 2026-08-05

設定画面では、以下の項目を変更できる。

- ユーザーネーム
- 自己紹介テキスト
- 装備中の称号
- BGMのオン／オフ
- SEのオン／オフ

ユーザーネームは1文字以上8文字以内、自己紹介テキストは最大200文字とする。ユーザーネームと自己紹介テキストの変更は、`spec_social_profile_guild_communication.md`に定義したとおり、各項目につきJST日次で1回までとする。

音響設定はユーザー単位で保存し、BGMとSEを個別に切り替えられるようにする。

本作はブラウザゲームであるため、プッシュ通知の設定・許諾導線・設定項目は設けない。通知が必要な情報は、ゲーム内のお知らせ、プレゼント、ミッション、バッジ等の画面内導線で提供する。
