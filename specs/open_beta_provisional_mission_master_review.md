# Open Beta暫定ミッションマスタ レビュー案

## 位置づけ

- `spec_mission.md`の確定事項（デイリー／通常、04:00 JST、通常の段階解放、マスタ駆動）に従う。
- 内容・数量はOpen Beta用の暫定値であり、全行を`is_provisional = true`として管理する。
- 安定したミッションIDをキーにupsertできるため、タイトル・条件・報酬は後からDBマスタだけで差し替え可能とする。
- 初回投入時は旧暫定行を無効化し、下記セットだけを有効にする。既存ユーザーの受取済み状態は保持する。
- Open Beta初期は、サーバーRPCで確実に記録できるイベントだけを採用する。PvP、GvG、レイド、ガチャは各結果確定RPCへの接続後に追加する。

## 未採用トリガー

| trigger | 理由 |
| --- | --- |
| `PVP_WIN` | PvP結果確定RPCへサーバー側接続後に追加する |
| `GVG_WIN` | GvG結果確定・重複防止と同時に追加する |
| `RAID_CLEAR` | レイド参加／討伐のどちらを数えるか確定後に追加する |
| `GACHA_PULL` | ガチャコアRPC側の重複不能な結果IDと接続後に追加する |
| `USER_INVITE` | 招待機能はOpen Beta MUSTの後段であり、現時点では投入しない |

## レビュー項目

1. デイリー4件という量と、日次報酬総量。
2. 通常ミッションを「解放後の追加回数」とすること。
3. ギルド加入報酬のガチャチケット ×3。
4. 暫定名称「万能カスタムツール[装備]」を今回も維持すること。
5. PvP／GvG／レイド／ガチャ系を安全な結果確定経路の完成まで除外すること。
