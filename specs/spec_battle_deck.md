# 個別企画仕様書(A)：抗争バトルシステム ＆ デッキ編成 (再設計版)

本作の戦闘は、歓楽街の覇権を争う裏社会のキャラクターに、所持スキルとハクスラ装備を組み合わせ、動的なタイムライン（SPD）と可変するAP（アクションポイント）を管理して戦う、完全オート進行の個別HPターン制バトルです。

---

## 1. デッキ・パーティ編成のルール

### ① バトルメンバー（最大5名）
- プレイヤーは最大5人のキャラクターを戦闘メンバー（部隊）として編成します。
- 各キャラクターは個別のステータス（HP, ATK, DEF, SPD, LUK）および固定のパッシブ特性（属性）を持ちます。

### ② キャラクターごとの装備スロット (計7スロット)
1. **武器スロット (2枠)**：専用武器スロット、または汎用武器。
2. **防具スロット (3枠)**：頭、胴、足（または汎用防具スロット3枠）。
3. **アクセサリースロット (2枠)**：主にSPDやLUKを補正する汎用/専用アクセサリー。

### ③ 使用可能スキルプール (カード・デッキ・ドローの廃止)
- **手札や山札の廃止**: 山札から手札をドローしてカードを使用するシステムは撤廃されました。
- **スキルプール方式**: 各キャラクターは、自身のターンが回ってきた際、以下の「使用可能スキルプール」から直接発動スキルを決定します。
  1. キャラクターに装備されているスキル（`user_skills` でスロット 0〜5 にセットされたもの、最大6枠）。
  2. 共通の基本スキル（通常攻撃、通常防御など）。
- **戦闘中のアイテム不使用**: バトル中に消費アイテムを使用することはできません。

## 2. 出撃準備（SETUP） ＆ 作戦選択

戦闘開始前、プレイヤーは **出撃準備画面（SETUP）** で以下の準備を行います。

- **情報の確認**:
  - **左側 (自部隊)**: 編成5名のキャラクターの縦長カード（イラスト、レベル、HP、装備スキル）、および算出された部隊の最大AP上限値。
  - **右側 (敵情報)**: 敵（NPCボススペック、またはPvP時の相手5人編成カード）。
- **詳細ポップアップ**: キャラクターカードをタップすることで、現在のステータス・装備・スキルを閲覧できます（※変更は不可）。
- **作戦選択**:
  - バトル開始前に、以下の **6つの作戦** から1つを選択します。バトル中（PLAYING）は作戦変更できず、最後までオート進行を見守ります。

| 作戦名 | HP状況 | 最優先するスキルタイプ | ターゲット選定 / 効果対象 |
| :--- | :--- | :--- | :--- |
| **攻撃重視 (OFFENSIVE)** | 不問 | `ATTACK` (最も威力が高いスキル) | 敵（最もHP割合が低い対象を集中攻撃） |
| **防御重視 (DEFENSIVE)** | 不問 | `DEFENSE` (挑発、シールド、全体防御バフ) | 自身、または味方全体 |
| **回復重視 (HEALING)** | いずれかの味方HPが70%以下 | `HEAL` (最も回復量の高いスキル) | HP割合が最も低い生存味方 |
| | 全員のHPが70%超 | 通常のバランス行動 (攻撃/防御) | 敵、または自身 |
| **バランス (BALANCED)** | 味方HPが50%以下 | `HEAL` ＞ `DEFENSE` ＞ `ATTACK` | 状況に応じて味方または敵 |
| | 味方HPが50%超 | `ATTACK` ＞ `DEFENSE` | 敵、または自身 |
| **速攻/AP温存 (AP_CONSERVING)**| 不問 | 得意スキル（シナジーAP軽減対象）を最優先 | 敵、または自身（AP蓄積を優先） |
| **支援/妨害重視 (TACTICAL)** | 不問 | `SUPPORT` (バフ) / `JAMMER` (デバフ) | バフ：味方全体 / デバフ：敵全体 |

## 3. バトル進行 ＆ AP・スキル発動ロジック

### ① SPD（速度）による動的タイムライン進行
- 生存している敵・味方すべてのキャラクターの **SPD** に基づいて、行動順（タイムライン）が決定されます。
- 行動ターンが回ってきたキャラクター（生存者のみ）が、作戦AIに基づき自動的にアクションを実行します。

### ② 得意スキルボーナス（AP軽減シナジー）
- キャラクターが装備しているスキルカードが得意スキルである場合（スキルの `exclusive_character_id`（ownerId）と、装備しているキャラクターのIDが一致している場合）、自動スキル発動時の消費APが **-1 軽減** されます（※最低消費APは1まで）。
- **威力上昇や持続ターン延長などの補正は適用されません。** 記載スペックのまま等倍で発動します。

### ③ 可変最大APシステム
- 部隊の最大AP上限値は、出撃メンバーの育成度と装備効果によって可変となります。
  - **最大AP算出式**:
    \[
    \text{最大AP} = 5 + \lfloor \frac{\text{編成メンバー5名のレベル合計}}{100} \rfloor + \text{装備アビリティによるAP上限加算値}
    \]
    ※最大APの範囲は **5 〜 15** とします。
- **APの回復**: 味方キャラクターのターン開始時に **+3 回復** し、最大APを超えて蓄積はしません。敵キャラクターのターンでは回復しません。
- **AP枯渇・温存時のフォールバック**:
  - APが不足して装備スキルが使えない場合、または「AP温存」作戦中にAP蓄積を優先する場合は、**消費AP 0（または1）の「通常攻撃」「通常防御」などの基本スキル**をフォールバックとして強制発動します。

## 4. 個別HPシステム ＆ 生存判定

- **個別HP管理**: 5名の味方はそれぞれ独立したHPバーを持ちます。
- **敵のターゲット選定**:
  - 味方の中で「挑発状態（防御スキルで付与、効果2ターン）」のキャラクターがいれば最優先で狙い、いなければランダム、または現在HP割合が最も低いキャラクターを狙います。
- **戦闘不能と勝敗判定**:
  - HP 0 になったキャラクターは「戦闘不能」となり、タイムラインから除外されます。
  - 味方5名全員が戦闘不能になると「敗北（DEFEAT）」。
  - 敵のHP（PvP時は敵5人全員のHP、レイド/NPC戦は敵ボスのHP）が 0 になると「勝利（VICTORY）」。

## 5. スキル効果パターンの拡張
バトルをより豊かにするため、以下の追加アビリティタイプを定義します。

1. **バトル開始時発動効果 (START_OF_BATTLE)**:
   - ターン開始前の戦闘イントロ時にトリガーされ、シールド付与やSPDアップ、敵へのデバフを自動展開します。
2. **常時パッシブ効果 (PASSIVE)**:
   - 装備しているキャラが生存している限り、常に効果（HP30%以下で与ダメアップなど）が発揮されます。
3. **条件付きトリガー効果 (TRIGGERED)**:
   - 攻撃を受けた際の確率反撃（カウンター）や、攻撃ダメージの一定割合をHP回復する（吸血）などの効果。

## 6. 戦闘演出 ＆ UI・進行シーケンス仕様 (改訂版)

### ① テキストログボックスの撤去 ＆ ビジュアル集約
- **常時テキストログボックスの全廃**: 画面領域を圧迫しUIを散らかす常時テキストログボックスは戦闘画面から撤去・全廃します（※リザルトでの簡易確認のみ）。
- **戦況表示の完全ビジュアル化**: すべての戦況は「カットイン・大判スキル名刻印」「ターゲットライン」「被弾シェイク」「ダイナミック数値ポップアップ（ダメージ:赤/回復:緑/シールド:青）」のビジュアル演出に100%集約します。

### ② 直列タイマー停止シーケンス (直列進行フロー)
ユーザーの操作待ちが発生しないオートバトルのため、手番は以下の4ステップで直列かつ安全に進行します。
1. **【ステップ1: 手番決定】**: タイムライン(SPD順)で行動キャラ決定。
2. **【ステップ2: 演出再生フェーズ (バトル一時停止)】**: タイマーが一時停止し、レアリティに応じたカットイン＋大判スキル名刻印＋特殊エフェクト/SEが再生。
3. **【ステップ3: ダメージ・効果適用 ＋ 数値ポップアップ】**: 演出完了のジャストタイミングで内部計算適用。被弾キャラがシェイクし大判数値がポップアップ。
4. **【ステップ4: ネクストターン】**: 全滅チェック後、タイムラインが次のキャラへ移行。

### ③ 味方・敵共通の演出適用ルール
- プレイヤー側だけでなく、NPCエネミー・PvP対戦相手・GvG防衛部隊・レイドボス等の敵側がスキルを発動した際も、レアリティに応じたカットイン、大判スキル名刻印、特殊エフェクト、SEが全く同様に再生されます。

### ④ 通常攻撃の内部構造Nスキル化 ＆ システム排除ガード
- **内部処理の統一**: AP不足時や基本行動時の「通常攻撃」「通常防御」は、例外処理ではなく `ap_cost: 0`, `rarity: "N"`, `animation_type: "GENERIC_LIGHT"` のNランクスキルとして内部データ構造を統一・処理します。
- **所持・ガチャ排除システムガード**: これらは「システム基本スキル」であり、**ガチャ排出対象、ユーザー所持スキル（`user_skills` インサート不可）、売却対象、およびスキル装備変更モーダルから100%遮断・非表示**とします。戦闘実行時にバトルエンジンが自動補填して適用します。

### ⑨ 5桁〜6桁大桁ダメージのスケーリング ＆ 動的ダメージ計算仕様
- **割合防御減算モデル (大桁インフレ対応)**: ステータスインフレ時の計算破綻（攻撃完全無効化や即死）を防ぐため、割合防御減算式を導入します。
  \[ \text{基礎火力} = \text{ATK} \times \left(1 + \frac{\text{power}}{100}\right), \quad \text{カット率} = \frac{\text{DEF}}{\text{DEF} + 2000}, \quad \text{基本ダメージ} = \text{基礎火力} \times (1 - \text{カット率}) \]
- **単調さを防ぐ動的変動補正メカニクス**: バトルが単調化しないよう、毎回以下の動的要素を重ねて最終ダメージを算出します。
  \[ \text{最終ダメージ} = \text{基本ダメージ} \times \text{属性相性補正 (有利+20\% / 不利-15\%)} \times \text{乱数 (0.95〜1.05)} \times \text{クリティカル倍率 (発動時1.5〜2.0倍)} \]
  - **乱数揺らぎ (±5%)**: 最終ダメージに 0.95〜1.05 のランダム幅を乗算し、毎回の数値を自然に変動させます。
  - **LUK連動クリティカル**: `LUK` ステータスに基づき確率判定。発動時ダメージが1.5〜2.0倍に跳ね上がり、`CRITICAL!` のビビッド表示と画面激シェイク演出が発生します。
- **3桁カンマ表記 ＆ 可変フォントスケーリング**: ダメージ数字は3桁区切りカンマ（例: `125,400`）でポップアップ表示し、CSS `clamp()` により縦長コンテナ内に美しく収まるように可変制御します。

### ⑤ レアリティ別4段階演出 ＆ スキル名刻印
- **Nランク (通常攻撃含む)**: 汎用簡易エフェクト (0.3秒)。頭上ミニ・トースト表示 (12px白)。
- **Rランク**: 汎用標準エフェクト (0.4秒)。画面下部スマート・テキストバナー表示 (16px白)。
- **SRランク**: キャラカットイン帯 (0.6秒)。シルバーベゼル帯＋立ち絵＋刻印スキル名 (22px極太白)。
- **SSR / 専用**: 豪華暗転カットイン (1.0秒)。画面全体暗転 (`fx_screen_darken`)＋金黒重厚ベゼル＋画面中央ド真ん中に大判刻印スキル名 (32px金白)＋専用特殊アセットエフェクト。

### ⑦ 装備品バフの開幕一括演出 ＆ 演出衝突の防止
- **開幕一括表現**: 装備品やパッシブ特性による能力上昇・開幕シールド付与などは、**戦闘開始イントロ（`launchBattlePlaying`）時に一括して短いエフェクトでまとめ表現**します。
- **スキル演出の非衝突**: バトル進行中（`PLAYING`）には装備品の個別演出を一切割り込ませず、スキルの4段階演出と100%分離させてテンポロスと演出の衝突を完全に防止します。

### ⑪ セキュリティ ＆ チート防止アーキテクチャ (Anti-Cheat Architecture)
- **サーバーサイド厳格検証 (Supabase RPC ＆ RLS)**: 勝敗判定、ポイント加算、報酬付与、アイテム消費などの重要処理は、クライアント端末側からの直接UPDATEを厳禁とし、すべて Supabase の RPC (Stored Procedure) 内でユーザー認証・所持条件・消費条件をダブルチェックした上でアトミックに確定します。
- **バトルセッション検証 ＆ 異常値自動リジェクト**: 戦闘開始時に DB へ `battle_sessions` を発行し、終了時に経過時間・ターン数・ステータス限界値をサーバー側で照合。クライアント側でのパラメータ改変や短時間撃破チートを自動検出・無効化します。

## 7. 友達 ＆ 助っ人システム（6人目部隊参戦）仕様

他プレイヤー（または友達）が設定した助っ人キャラクターを1名借りて出撃し、自部隊5名 ＋ 助っ人1名の **最大6人部隊** でバトルに参戦するソーシャル連動機能です。

### ① 助っ人設定 ＆ 友達一覧
- **助っ人設定**: プレイヤーは自身の所持キャラクターから1名を「助っ人」として `user_support_characters` テーブルに設定・公開できます。
- **友達上限（最大30人）**: 友達の登録上限は最大30人。構成員プロフィール（自己紹介モーダル）の「＋ 友達申請」ボタンや、友達画面（「友達を探す」タブ）から申請・承認が可能です。

### ② 6人目部隊としてのバトル参戦 ＆ ターン計算 (`useBattle.ts`)
- 出撃準備画面（`SETUP`）で助っ人を選択して出撃すると、助っ人のステータス・装備・スキルデータが `useBattle.ts` により味方部隊の **6番目の参戦スロット (`support_xxx`)** に動的挿入されます。
- 助っ人は他の味方5名と同様に、自身の **SPD** に従った動的タイムライン行動順に組み込まれ、得意スキル（`ownerId`一致で消費AP -1軽減）などのオートAIスキル判定がそのまま適用されます。
- **友達ポイント（FP）の排除**: 友達ポイント（FP）機能は存在せず、ポイント加算処理は行われません。助っ人は純粋に6人目の味方として戦闘を共闘・サポートします。
