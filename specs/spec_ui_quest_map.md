# 個別企画仕様書(F)：UI構成 ＆ クエスト派遣 ＆ 1枚マップ移動 ＆ 設定・購入仕様

本作のユーザーインターフェース（UI）の動線、派遣型のクエスト進行、1枚絵マップによる即時移動、およびユーザー設定や購入に関するその他仕様です。

---

## 1. 拠点中心のUI構造 ＆ 画面動線

プレイヤーがゲームにログインした際、または拠点に滞在している際の基本画面（拠点トップ）のUI構成と各機能への動線設計です。

### ① マイページ兼・拠点トップ画面
- **ビジュアル**: 
  - 滞在している拠点（ネオンタワー、ディープドックなど）の背景ビジュアルを全画面で表示。
  - 画面中央には、お気に入り設定されたリーダーNPCの **「美麗静止画イラスト（立ち絵・ポートレート）」** が表示されます（※今回はLive2D等のアニメーションは行わず、クオリティの高い2D静止画を表示します）。
- **画面動線**:
  - **【シノギ（派遣）】** ➔ 新宿〜横浜の21クエストへの派遣選択画面へ。
  - **【PvP（PvP）】** ➔ PvPへ。
  - **【ギルド (Guild)】** ➔ チャットやGvG（拠点支配）、ギルド管理へ。
  - **【掲示板 (Community)】** ➔ 掲示板（暗号化SNS『TRIBE』）へ。
  - **【ガチャ・ショップ (Store)】** ➔ 購入・ガチャへ。
  - **【育成 (Upgrade)】** ➔ キャラ・スキル・装備強化へ。
  - **【マップ (Map)】** ➔ モバイル1画面の4大拠点マップへ。

## 2. クエスト（派遣・シノギ）の仕様 (放置派遣方式)

通常のクエストはバトル操作やシナリオ演出を排除し、キャラクターを一定時間派遣してアイテムを獲得する **放置派遣方式** を採用します。

### ① クエスト派遣（シノギ）仕様
- **派遣先と難易度（コース）**:
  - 派遣先として新宿、渋谷、池袋、六本木、秋葉原、川崎、横浜の7箇所を選択可能。
  - それぞれに「初級」「中級」「上級」があり、計21クエストが存在します。
  - **初級（シノギの例：見回り）**: 所要時間 **15秒**（仕様上は1時間）、消費スタミナ **10**。獲得報酬：下級素材（指南書、研磨石、傷薬）、少額キャッシュ。
  - **中級（シノギの例：用心棒 / ショバ代徴収）**: 所要時間 **45秒**（仕様上は4時間）、消費スタミナ **30**。獲得報酬：中級素材、中額キャッシュ、低確率でR〜SR装備・スキル。
  - **上級（シノギの例：利権争い / 密輸支援）**: 所要時間 **120秒**（仕様上は8時間）、消費スタミナ **50**。獲得報酬：上級素材（抗争の掟）、高額キャッシュ、低確率でR〜SSR装備・スキル。
- **同時並行派遣（最大5枠）とロック（重複派遣制限）**:
  - プレイヤーは1つのクエストにつき1名のキャラクターを選択し、同時に最大5つのクエスト（最大5枠）を並行して派遣進行させることができます。
  - **重複制限**: 現在出撃中（ONGOING）のキャラクターは、派遣が完了して報酬を回収するまで、他の派遣コースへ重複して出撃させることはできません。
  - **共存許可**: 派遣中であっても、PvPの防衛デッキ登録や、24時間レイドバトル（非同期）への参加は制限なく実行可能です。
- **地元一致ボーナス（LUKボーナス）**:
  - キャラクターマスタに定義された地元（`homeTown`）と、派遣先の街（新宿など）が一致している場合、派遣されたメンバーの LUK 値の合計に基づいて報酬ボーナスが付与されます。
  - **ドロップ率ボーナス**: ドロッププール内のアイテム獲得確率が `+ (LUK合計 * 0.1)%` 上昇します。
  - **獲得キャッシュボーナス**: 獲得基本キャッシュに `+ (LUK合計 * 10)` が加算されます。
- **ユーザー経験値（XP）の獲得**:
  - 派遣任務の完了報酬を回収する際、クエストごとに設定された消費スタミナ（Vitality）の10倍のユーザー経験値（初級100 xp, 中級300 xp, 上級500 xp）が直接加算されます（プレゼントボックスは経由しません）。
- **報酬のプレゼントボックス送付**:
  - キャッシュやドロップアイテムを含むすべてのクエスト報酬は、直接加算されず、一度 **プレゼントボックス（presents）に UNCLAIMED 状態** で送られ、ユーザーが受取ることで反映されます。
- **即時帰還（時短完了）**:
  - 派遣残り時間に応じたコストを支払うことで、即座に帰還完了（CLAIMABLE）として報酬を得ることができます。
  - **キャッシュ消費**: 残り1分につき100キャッシュ。インフレ防止のため **「1日3回まで」** の使用回数制限を設定。
  - **ダイヤ消費**: 残り1時間あたり10ダイヤ（切り上げ）。使用回数制限は **「無制限」**。

### ② 派遣ログ（経過報告）
- 派遣中の画面にスクロール可能な「派遣ログモニター」を表示し、シノギ中の状況をテキストログで視覚化します。
- クライアント側またはRPC側で、経過時間に応じたランダムなログ（キャッシュ獲得やアイテム発見など）を動的にリスト表示します。

#### 経過ログのテキストテンプレート（例：新宿エリア・中級）：
> - `[12:00] 歌舞伎町エリアで見回り派遣を開始した。`
> - `[12:30] 半グレグループの乱闘に介入。レイジが威嚇し、キャッシュ +500 を獲得。`
> - `[13:00] 地下駐車場で放置されたトランクを発見。「カスタム研磨石」を1個入手。`
> - `[14:00] グレア・エージェンシーからの上納金を回収。キャッシュ +2,000 を獲得。`
> - `[15:30] 闇薬局の仕入れルートを確保。「傷薬」を2個入手。`
> - `[16:00] 時間経過により派遣任務完了。拠点へ帰還。`

## 3. モバイル1画面・4大拠点マップ仕様

アングラ世界の4つの主要拠点（ネオンタワー、ディープドック、ジャンクバザール、キタクラゲート）を、スマートフォンの縦1画面（スクロールなし）に収め、各勢力の支配状況を直感的に把握するための背景・レイアウト設計です。

### ① 「アングラ4大拠点マップ」スタイル
モバイル縦画面にデフォルメされた、**「TOKYOの夜に浮かび上がる4つの重要アングラ拠点を描いた鳥瞰イラスト」** を全画面背景マップとして使用します。

* **ビジュアルの構成**:
  - **ネオンタワー (Neon Tower)**: 商業・オフィス複合超高層タワー。高級キャバクラや闇取引を象徴する、富裕層とサイバー犯罪者の指令城。夜空にそびえ立つ複合商業ビル（※過度なSFサイバー調を避け、リアルな歓楽街ビル）。
  - **ディープドック (Deep Dock)**: 重厚な港湾設備と薄暗い廃倉庫群。コンテナ密輸ルート、地下格PvP、ストリートギャングのたまり場。
  - **ジャンクバザール (Junk Bazar)**: 雑多なネオン看板とジャンク電子パーツがひしめく闇市。違法ハッキングチップ、ジャンク武器密売、闇情報ネットワークの巣窟。
  - **キタクラゲート (Kitakura Gate)**: 伝統的な和風ネオン看板と鉄骨が入り乱れる歓楽街の入口。伝統的暴力団『黒曜会』の牙城。闇スロット店・裏バカラの運営権を握る武闘派組織の総本山。
* **インターフェース（UI）表示**:
  - 各拠点の位置に、ネオン調の **「ピン（マーカー）」** を配置。
  - ピンをタップすると、拠点詳細パネルが表示され、**「支配ギルド名」「レイド警告アイコン」「占領ポイント数」** などが表示されます。
  - 「移動」を押すと瞬間移動（ロード時間を除き即時、コスト消費なし）します。所属拠点という概念はありませんが、拠点間の移動は自由に行えます。
  - **メリット**: アングラTOKYOの覇権争いというコンセプトが最も強くプレイヤーに体感され、自分のギルドが支配している拠点を視覚的に実感できます。

## 4. ユーザー設定画面（マイ設定）

- **お気に入りキャラクター設定**: 所持NPCから選択、静止画アイコンを表示。
- **通り名（称号）の選択・変更**: 獲得した通り名（例：『歌舞伎町の覇王』）の装備。
- **ギルド管理**: 設立、検索、脱退。GvGランク・開催中マッチング・報酬受取資格への影響は、GvG仕様で別途定義する。
- **音量設定 (Volume Settings)**: BGM、SE、ボイス音量を個別にスライダ調整。

## 5. ガチャ ＆ Stripe決済における購入確認要件

- **ダイヤ・パッケージ購入確認 (Stripe)**:
  - Stripeの決済画面に遷移する直前に、購入内容と「Stripeの外部決済画面へ移行します」という旨を示す確認ダイアログを表示。
- **アイテム・ガチャ購入確認**:
  - ゲーム内ショップやガチャ実行時に「〇〇を消費して実行します。よろしいですか？」という最終確認ポップアップを表示。
